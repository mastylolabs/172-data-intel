## Intent, actors, scope and non-goals

An isolated synthetic-demo session selects a full approved source identity, asks a question, sees truthful progress or clarification, and receives an answer only after independent validation. Refresh retains selected source, accepted conversation and inspectable evidence; a follow-up uses accepted same-source context without converting a rejected candidate into a fact. An operator/QA engineer independently checks provenance, lifecycle and refusal outcomes.

M4-C0 defines the contract and review obligations only. Subsequent M4 scope is bounded profile/query/search/clarify planning, Python tool coordination, candidate claims/citations, a separate Llama 3.3 Validator invocation, atomic accepted publication, durable memory and interruption/isolation/budgets. The Orchestrator controls authority; the Data Profiler is deterministic; the Semantic role runs only when meaning is missing and must clarify instead of inventing it; the Analyst proposes; the independent Validator challenges.

Non-goals: M5 web chat/screens/public-access rollout, changing the SQLite/runtime boundary or fixture meanings, cross-source joins/causal links, arbitrary sources, uploads/connectors/OAuth, PostgreSQL/Parquet/vector search/full-corpus classification, containers/distributed execution/benchmarks, accounts/private data, paid LLMs or reference-resource changes. No claim of guaranteed background completion, physical exactly-once execution or provider-backup deletion.
